# Btech Market V2 Roadmap

## Phase 0 — Foundation
Architecture, repository standards, environment setup, schema design and CI.

## Phase 1 — Transaction MVP
Customer storefront, catalogue/search, product detail, authentication, cart, checkout and orders. Seller Center supports onboarding, listings, inventory and fulfilment. Admin receives minimum operational controls.

## Phase 2 — Trust and Marketplace Operations
Seller verification, device diagnostics, IMEI/activation-lock workflow, grading evidence, seller metrics, returns, warranty claims, fraud controls and payout holds/releases.

## Phase 3 — Trade-in / Recommerce
Quote engine, inbound shipment, inspection, condition mismatch/requote, acceptance and payout. Supply can be routed to participating refurbishers/buyers rather than requiring Btech to purchase every device.

## Phase 4 — Scale
Dedicated search if needed, analytics, multi-currency/market expansion, performance optimisation and selective service extraction only where justified.

## Build rule
Every phase must be demonstrably working end-to-end before expanding infrastructure or adding nonessential complexity.
